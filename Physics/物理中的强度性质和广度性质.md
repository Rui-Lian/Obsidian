
|          | 定义             | 举例                                                              | 特点         |
| -------- | -------------- | --------------------------------------------------------------- | ---------- |
| **广度性质** | 和系统，对象的大小、数量有关 | 质量、体积、电荷、能量、功、电容                                                | 整体值等于部分值之和 |
| **强度性质** | 和系统，对象的大小、数量无关 | 温度：100度+100度= 100度 Pressure：1atm + 1atm = 1atm; 密度、速度、加速度、时间、电压 | 整体值和部分值相等  |
